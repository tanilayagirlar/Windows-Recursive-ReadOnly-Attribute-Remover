# Windows-Recursive-ReadOnly-Attribute-Remover
Windows dosya ve klasör ağacındaki ReadOnly özniteliğini özyinelemeli olarak kaldıran PowerShell scripti. Büyük klasör yapılarında bellek tüketimini düşük tutarak çalışır; yapılan değişiklikleri ve oluşan hataları zaman damgalı CSV log dosyasına kaydeder.
